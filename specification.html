Доработка справочника "Онлайн-продукты": комплекты документов

СистемаПрограммный комплекс "Гибридное электронное досье клиента" (ГЭДК) Версия документа1.6 Дата29.09.2026 СтатусПроект для согласования

Изменения версии 1.6 выделены красным. Спецификация ограничена настройкой комплектов в справочнике "Онлайн-продукты". Логика и ошибки онлайн-верификации, Use Case проверки и требования к отчетам исключены из документа и должны быть учтены в UC-68. Разрешено отсутствие комплектов у продукта и удаление последнего комплекта. Требование выделять все дублирующие строки удалено.

Цель доработки

Обеспечить настройку в справочнике "Онлайн-продукты" от нуля до пяти альтернативных комплектов документов для разных способов оформления продукта.

Система или участникОтветственность

ГЭДКПрисваивает номера комплектам, хранит их порядок, проверяет заполнение и ограничения настройки.

  • Обеспечивает отсутствие старых активных настроек после перехода.

Бизнес-правила

КодПравилоОписание
BR-001Самодостаточность комплектаКаждый комплект должен содержать все документы, необходимые для соответствующего способа оформления онлайн-продукта. Документы, обязательные для всех способов оформления, отдельно не настраиваются. Такие документы необходимо включать в каждый комплект.
BR-002Автоматические операторыПользователь не выбирает логический оператор. Оператор "И" объединяет документы одного комплекта. Оператор "ИЛИ" обозначает, что комплекты являются альтернативными.
BR-003ПорядокПорядок комплектов определяется порядком их создания и отображается автоматически присвоенным номером.
BR-008Уникальность документа внутри комплектаВ одном комплекте не допускаются две или более строки с одинаковыми значениями полей "Вид документа" и "Подвид документа". Одинаковая пара значений в разных комплектах допускается.
BR-009Количество комплектовДля одного онлайн-продукта может быть настроено от нуля до пяти комплектов.

Функциональные требования

Настройка справочника

КодТребованиеОписание
FR-GEDK-001Отображать комплектыНа вкладке "Комплекты документов" ГЭДК должен отображать документы выбранного продукта с группировкой по комплектам. Если комплекты отсутствуют, ГЭДК должен отображать пустое состояние вкладки.
FR-GEDK-002Создавать комплектПо действию "Добавить комплект" ГЭДК должен создать новый комплект после всех существующих комплектов продукта.
FR-GEDK-003Присваивать номерГЭДК должен автоматически присвоить новому комплекту следующий номер без участия пользователя.
FR-GEDK-004Отображать наименование комплектаГЭДК должен отображать наименование каждой группы документов в формате "Комплект N", где N - автоматически присвоенный номер комплекта.
FR-GEDK-005Добавлять документПользователь должен иметь возможность добавить строку документа внутрь выбранного комплекта с заполнением существующих полей комплекта.
FR-GEDK-006Изменять документПользователь должен иметь возможность изменить существующую строку документа внутри комплекта.
FR-GEDK-007Удалять документПользователь должен иметь возможность удалить строку документа из комплекта.
FR-GEDK-008Удалять комплектПользователь должен иметь возможность удалить выбранный комплект, включая единственный комплект онлайн-продукта.
FR-GEDK-009Перенумеровывать комплектыПосле удаления комплекта ГЭДК должен перенумеровать оставшиеся комплекты от 1 без пропусков, сохранив их взаимный порядок. Если удален последний комплект, перенумерация не выполняется.
FR-GEDK-010Требовать документ в созданном комплектеГЭДК не должен сохранять настройку продукта, если созданный комплект не содержит ни одной полностью заполненной строки документа. Отсутствие комплектов у продукта не является ошибкой.
FR-GEDK-011Показывать операторыГЭДК должен отображать "И" между документами одного комплекта и "ИЛИ" между комплектами как неизменяемые элементы интерфейса.
FR-GEDK-012Сохранять действующие поляДля строки документа должны сохраняться существующие поля: вид досье, вид документа, подвид документа и применимые атрибуты связки.
FR-GEDK-013Применять действующие праваПросмотр и изменение комплектов должны использовать действующие права на просмотр и изменение справочника "Онлайн-продукты". Новая роль данным ТЗ не вводится.
FR-GEDK-014Проверять строку документаГЭДК не должен сохранять настройку продукта, если обязательное существующее поле хотя бы одной строки документа не заполнено.
FR-GEDK-015Не отображать статусы комплектовГЭДК не должен отображать для комплектов пометки "Основной", "Альтернативный" или иные признаки категории комплекта.
FR-GEDK-016Проверять уникальность документовПри сохранении настройки ГЭДК должен проверить каждый комплект на наличие строк с одинаковыми значениями полей "Вид документа" и "Подвид документа". При обнаружении хотя бы одной одинаковой пары ГЭДК не должен сохранять настройку продукта.
FR-GEDK-017Сообщать о повторении документаЕсли в одном комплекте обнаружены строки с одинаковыми значениями полей "Вид документа" и "Подвид документа", ГЭДК должен показать сообщение о повторении документа внутри комплекта.
FR-GEDK-018Ограничивать количество комплектовЕсли для онлайн-продукта уже настроено пять комплектов, ГЭДК не должен создавать шестой комплект и должен показать сообщение о достижении максимального количества комплектов.
FR-GEDK-019Не хранить версии настройкиГЭДК не должен создавать пользовательскую историю версий настройки комплектов.

Требования к переходу на новую структуру данных

КодТребованиеОписание
FR-DATA-001Подготовить импортируемые настройкиВендор должен подготовить набор данных, позволяющий загрузить целевые комплекты для существующих продуктов без ручного ввода строк через интерфейс.
FR-DATA-002Обеспечить полную заменуПосле перехода в действующей конфигурации не должны одновременно использоваться старые строки комплекта и новые комплекты.
FR-DATA-003Удалить старые настройкиПосле подтверждения загрузки новых данных старые настройки должны быть удалены из действующей конфигурации.
FR-DATA-004Выбрать технический способ переходаФормат файла, порядок загрузки, технический способ удаления и процедура переключения определяются вендором и не задаются настоящим ТЗ.
FR-DATA-005Проверять уникальность импортируемых документовДо загрузки новых настроек вендор должен проверить каждый импортируемый комплект на наличие строк с одинаковыми значениями полей "Вид документа" и "Подвид документа". При обнаружении одинаковой пары загрузка новых настроек не должна начинаться до устранения дубликата.
FR-DATA-006Проверять количество импортируемых комплектовДо загрузки новых настроек вендор должен проверить количество комплектов каждого онлайн-продукта. Если для продукта подготовлено более пяти комплектов, загрузка новых настроек не должна начинаться до сокращения их количества.

UI-KIT-R02Комплект не содержит документов.ГЭДК показывает сообщение "Добавьте хотя бы один документ". Сохранение настройки недоступно до добавления хотя бы одного полностью заполненного документа.
UI-KIT-R03Настроено менее пяти комплектов, пользователь нажал "Добавить комплект".ГЭДК создает пустой комплект после существующих и автоматически присваивает ему следующий номер.
UI-KIT-R04Настроено пять комплектов, пользователь нажал "Добавить комплект".ГЭДК не создает шестой комплект и показывает сообщение о достижении максимального количества комплектов.
UI-KIT-R05Пользователь выбрал удаление комплекта.ГЭДК показывает подтверждение удаления комплекта со всеми входящими документами. Если после удаления останутся другие комплекты, сообщение содержит предупреждение об их перенумерации.
UI-KIT-R06Пользователь подтвердил удаление комплекта.ГЭДК удаляет комплект. Оставшиеся комплекты перенумеровываются от 1 без пропусков с сохранением взаимного порядка. Если удален последний комплект, ГЭДК отображает пустое состояние вкладки.
UI-KIT-R07Пользователь отменил удаление комплекта.Диалог закрывается. Состав и номера комплектов не изменяются.
UI-KIT-R08Пользователь удаляет единственный комплект.После подтверждения ГЭДК удаляет комплект и отображает пустое состояние вкладки. Отсутствие комплектов не считается ошибкой настройки.
UI-KIT-R09Пользователь нажал "Добавить документ" при наличии хотя бы одного комплекта.ГЭДК открывает форму добавления документа. В списке "Комплект" доступны существующие комплекты выбранного продукта. При отсутствии комплектов действие недоступно.
UI-KIT-R10Пользователь не заполнил хотя бы одно обязательное поле и нажал "Добавить".Документ не добавляется. Форма остается открытой, незаполненные поля обозначаются как ошибочные.
UI-KIT-R11В выбранном комплекте уже существует строка с указанными видом и подвидом документа.Документ не добавляется. Поля "Вид документа" и "Подвид документа" обозначаются как ошибочные, пользователю показывается сообщение о повторении документа.
UI-KIT-R12Такая же пара вида и подвида документа существует в другом комплекте.Документ может быть добавлен в выбранный комплект.
UI-KIT-R13Обязательные поля заполнены, дубликат внутри выбранного комплекта отсутствует, пользователь нажал "Добавить".ГЭДК добавляет строку в выбранный комплект, закрывает форму и обновляет количество документов.
UI-KIT-R14Пользователь выбрал строку документа.Строка выделяется, действие "Удалить" становится доступным.
UI-KIT-R15Пользователь подтвердил удаление выбранного документа.ГЭДК удаляет строку из комплекта и обновляет количество документов. Если комплект стал пустым, сохранить настройку нельзя до добавления документа.
UI-KIT-R16Пользователь сохраняет настройку, содержащую созданный пустой комплект или незаполненную строку.Настройка не сохраняется. ГЭДК выделяет комплект или строку и показывает причину ошибки. Если комплекты отсутствуют, данная проверка не применяется.
UI-KIT-R17Пользователь сохраняет настройку с одинаковой парой вида и подвида документа внутри одного комплекта.Настройка не сохраняется. ГЭДК показывает сообщение о повторении документа внутри комплекта.
UI-KIT-R18Настройка соответствует ограничениям, пользователь нажал "Сохранить".ГЭДК сохраняет настройку целиком и показывает сообщение об успешном сохранении. Настройка без комплектов также может быть сохранена.
UI-KIT-R19Пользователь нажал "Обновить".ГЭДК повторно загружает сохраненную настройку выбранного продукта и отменяет несохраненные изменения на вкладке.
UI-KIT-R20ГЭДК отображает документы и комплекты.Операторы "И" и "ИЛИ" формируются автоматически и недоступны пользователю для изменения.

Use Case UC-KIT-01 - настройка комплектов

ЦельНастроить для онлайн-продукта от нуля до пяти самодостаточных комплектов.
УчастникУполномоченный пользователь ГЭДК.
ТриггерПользователь открывает вкладку "Комплекты документов" выбранного продукта.
Предусловия
  • Продукт существует.
  • Пользователь имеет действующее право изменения справочника.
Успешное постусловиеНастройка сохранена. При наличии комплектов они автоматически пронумерованы.
Неуспешное постусловиеНастройка не изменена. Пользователю показана причина ошибки заполнения либо повторения документа.

Ошибки и исключения настройки

КодСитуацияУсловиеПоведение ГЭДКИтог
EXC-KIT-001Пустой созданный комплектУ продукта существует комплект, который не содержит ни одной полностью заполненной строки документа.
  • Не сохранять настройку.
  • Выделить пустой комплект или незаполненную строку.
  • Показать сообщение "Добавьте хотя бы один документ и заполните обязательные поля".
Прежняя настройка остается действующей. Если у продукта нет комплектов, ошибка не возникает.
EXC-KIT-006Дублирование документа внутри комплектаВ одном комплекте существуют две или более строки с одинаковыми значениями полей "Вид документа" и "Подвид документа".
  • Не сохранять настройку продукта.
  • Показать сообщение о повторении документа внутри комплекта.
Прежняя настройка продукта остается действующей.
EXC-KIT-007Превышение количества комплектовДля онлайн-продукта уже настроено пять комплектов, и пользователь пытается добавить еще один комплект.
  • Не создавать новый комплект.
  • Показать сообщение о достижении максимального количества комплектов.
Для продукта сохраняются пять ранее настроенных комплектов.
