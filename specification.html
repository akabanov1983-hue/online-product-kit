Термины

ТерминОпределение
КомплектПолный набор документов, необходимый для одного способа оформления онлайн-продукта. В интерфейсе комплект обозначается словом "Комплект" и автоматически присвоенным номером.
Комплект 1Первый комплект по порядку создания или перенумерации. Если ни один комплект не выполнен полностью, только отсутствующие документы Комплекта 1 включаются в результат проверки. Отдельный статус комплекту не присваивается.
Выполненный комплектКомплект, по которому подтверждено выполнение действующих правил проверки для каждого входящего в него документа.
Расширенная проверка ind_doc_51Проверка документов вида ind_doc_51 в досье БПК и связанном досье счета по правилам UC-56.

Цель доработки

Исключить ошибочные результаты онлайн-верификации для продуктов, которые могут быть оформлены одним из нескольких полных комплектов документов. ГЭДК должен считать продукт успешно проверенным, если полностью выполнен хотя бы один настроенный комплект, и не должен требовать документы из остальных комплектов.

ОтчетыОтчеты имеют утвержденный состав полей.Состав полей не изменяется. Номер комплекта в отчет не добавляется.

Целевой процесс проверки

ГЭДК определяет онлайн-продукт и читает действующие настройки на момент начала проверки.
ГЭДК получает комплекты в порядке их номеров, начиная с комплекта 1.
ГЭДК проверяет все документы текущего комплекта по действующим правилам. Для комплекта с ind_doc_51 применяется расширенная проверка UC-56.
Если комплект выполнен полностью, ГЭДК фиксирует успешный результат и не проверяет последующие комплекты.
Если комплект не выполнен, ГЭДК переходит к следующему комплекту.
Если ни один комплект не выполнен, ГЭДК формирует расхождения только по отсутствующим документам комплекта 1.
ШагИсполнительВходДействиеРезультат
1ГЭДКЗапрос онлайн-верификацииОпределяет продукт по действующим правилам.Определен проверяемый продукт.
2ГЭДККод продуктаЧитает текущую настройку комплектов и фиксирует ее для данного запуска.Получен упорядоченный перечень комплектов.
3ГЭДКПервый непроверенный комплектПроверяет каждый документ комплекта.Для комплекта определен признак полного выполнения.
4ГЭДКПолностью выполненный комплектЗавершает проверку продукта.Результат успешный. Расхождения других комплектов отсутствуют.
5ГЭДКНевыполненный комплект и наличие следующегоПереходит к следующему номеру.Начата проверка следующего комплекта.
6ГЭДКНи один комплект не выполненВыбирает отсутствующие документы комплекта 1.Сформирован неуспешный результат без расхождений комплектов с номером 2 и далее, размещения и связи.

BR-001Полный комплектКаждый комплект содержит полный набор документов. Общий обязательный блок вне комплектов не используется.
BR-002Автоматические операторыПользователь не выбирает логический оператор: внутри комплекта всегда действует "И", между комплектами всегда действует "ИЛИ".
BR-003ПорядокПорядок комплектов определяется порядком их создания и отображается номером.
BR-004Комплект 1Если ни один комплект не выполнен полностью, Комплект 1 используется для формирования неуспешного результата по правилам FR-VER-010 - FR-VER-012.
BR-005Несколько совпаденийОдновременное соответствие нескольким комплектам рассматривается как дублирование способов оформления. Результат определяется по первому выполненному комплекту.
BR-006Неуспешная проверкаЕсли ни один комплект не выполнен, диагностический результат ограничивается отсутствующими документами комплекта 1.
BR-007Повторный запускПовторный запуск является новой проверкой и использует текущую настройку. Результат прежнего запуска не меняется.

Use Case UC-KIT-01 - настройка комплектов

ЦельНастроить для онлайн-продукта один или несколько полных комплектов.
УчастникУполномоченный пользователь ГЭДК.
ТриггерПользователь открывает вкладку "Комплекты документов" выбранного продукта.
Предусловия
  • Продукт существует.
  • Пользователь имеет действующее право изменения справочника.
Успешное постусловиеКомплекты сохранены, автоматически пронумерованы и доступны новым запускам проверки.
Неуспешное постусловиеНастройка не изменена, пользователю показаны незаполненные комплекты или строки.

Основной сценарий

  1. ГЭДК отображает существующие комплекты в порядке номеров.
  2. Пользователь добавляет новый комплект.
  3. ГЭДК присваивает комплекту следующий номер.
  4. Пользователь добавляет документы и заполняет существующие поля каждой строки.
  5. ГЭДК отображает "И" между документами и "ИЛИ" между комплектами.
  6. Пользователь сохраняет настройку.
  7. ГЭДК проверяет заполнение и сохраняет настройку.

Альтернативные сценарии

КодУсловиеПоведение
2аПользователь удаляет комплект.ГЭДК удаляет комплект и перенумеровывает оставшиеся комплекты без пропусков.
6аКомплект пуст или содержит незаполненную строку.ГЭДК отменяет сохранение и указывает место ошибки.
2бПользователь пытается удалить единственный комплект.ГЭДК не выполняет удаление и сообщает, что у продукта должен оставаться хотя бы один комплект.

Use Case UC-KIT-02 - проверка комплектов

ЦельОпределить успешность проверки продукта по одному из настроенных комплектов.
УчастникиУОС, ГЭДК.
ТриггерНовый или повторный запуск онлайн-верификации.
ПредусловияПродукт определен, его настройка содержит хотя бы один комплект.
Успешное постусловиеПервый полностью выполненный комплект определен, результат успешный, расхождения других комплектов отсутствуют.
Неуспешное постусловиеНи один комплект не выполнен, результат содержит только отсутствующие документы комплекта 1.

Ошибки и исключения

СитуацияУсловиеПоведение ГЭДКИтог
Пустой комплектКомплект не содержит полностью заполненной строки.Не сохранять настройку и выделить комплект.Прежняя настройка остается действующей.
Удаление единственного комплектаУ продукта существует один комплект.Запретить удаление.У продукта остается один комплект.
Ни один комплект не выполненПосле проверки последнего комплекта не найдено полного совпадения.Сформировать только отсутствие документов комплекта 1.Неуспешный результат.
Не определена связь досье для ind_doc_51Комплект требует документы связанного досье, но связь не позволяет однозначно продолжить проверку.
  • Считать комплект невыполненным.
  • При невыполнении всех комплектов включить в результат требуемые документы комплекта 1, наличие которых не подтверждено.
  • Не выводить отдельную ошибку связи.
Проверка продолжается со следующим комплектом или завершается по BR-006.
Документ найден в другом досьеТребуемое размещение не подтверждено.
  • Считать документ невыполненным для данного комплекта.
  • При невыполнении всех комплектов вывести отсутствие этого документа в составе комплекта 1.
  • Не выводить отдельную ошибку размещения.
Проверка продолжается или завершается по BR-006.
