Термины

ТерминОпределение
КомплектНабор документов, необходимый для одного способа оформления онлайн-продукта. В интерфейсе комплект обозначается словом "Комплект" и автоматически присвоенным номером.
Комплект 1Первый комплект по порядку создания. Если среди документов клиента не найден полный набор документов ни для одного из настроенных комплектов, в результат проверки включаются только отсутствующие документы Комплекта 1.
Полный комплект документовКомплект, для которого в досье клиента найдены все входящие в него обязательные документы и выполнены применимые правила их проверки.
Расширенная проверка ind_doc_51Проверка документов вида ind_doc_51 в досье БПК и связанном досье счета с применением действующих правил поиска документов и определения связи между досье.
Уполномоченный пользователь ГЭДКПользователь, которому предоставлены права на просмотр и изменение справочника "Онлайн-продукты".

Цель доработки

Исключить ошибочные результаты онлайн-верификации для продуктов, которые могут быть оформлены одним из нескольких комплектов. ГЭДК должен считать продукт успешно проверенным, если определен хотя бы один полный комплект документов, и не должен требовать документы из остальных комплектов.

Текущее и целевое состояние

ОбластьТекущее состояниеЦелевое состояние
Структура справочникаСтроки документов хранятся как единый перечень комплекта продукта.Строки объединяются в пронумерованные комплекты. Документы комплекта связаны условием "И", комплекты связаны условием "ИЛИ".
ПроверкаГЭДК проверяет каждую строку настройки продукта, что приводит к расхождениям по документам альтернативного способа оформления.ГЭДК проверяет комплекты по порядку и завершает проверку после определения первого полного комплекта документов.
Неуспешный результатВ результат могут попадать расхождения по каждой строке настройки.Если по результатам проверки полный комплект документов не определен, в результат включаются только отсутствующие документы Комплекта 1.
ОтчетыОтчеты имеют утвержденный состав полей.Состав полей не изменяется. Номер комплекта в отчет не добавляется.

Система или участникОтветственность

ГЭДКПрисваивает номера, хранит порядок, проверяет заполнение, применяет комплекты при онлайн-верификации и формирует результат.

Бизнес-правила

КодПравилоОписание
BR-001Самодостаточность комплектаКаждый комплект должен содержать все документы, необходимые для соответствующего способа оформления онлайн-продукта. Документы, обязательные для всех способов оформления, отдельно не настраиваются. Такие документы необходимо включать в каждый комплект.
BR-002Автоматические операторыПользователь не выбирает логический оператор: внутри комплекта всегда действует "И", между комплектами всегда действует "ИЛИ". Комплект признается полным, если успешно проверены все входящие в него документы. Для успешной проверки продукта достаточно определить один полный комплект документов.
BR-003ПорядокПорядок комплектов определяется порядком их создания и отображается автоматически присвоенным номером. Комплекты проверяются по возрастанию номера.
BR-004Комплект 1Если после проверки всех настроенных комплектов полный комплект документов не определен, ГЭДК формирует неуспешный результат: включает только документы Комплекта 1, наличие которых в требуемом месте не подтверждено, и не включает документы комплектов с номером 2 и далее.
BR-005Несколько совпаденийОдновременное соответствие нескольким комплектам рассматривается как дублирование способов оформления. Результат определяется по первому комплекту, признанному полным.
BR-006Неуспешная проверкаЕсли полный комплект документов не определен, в результат включаются только отсутствующие документы Комплекта 1. Ошибки размещения, отсутствия или неоднозначности связи и недоступности связанного досье в результат не включаются.
BR-007Повторный запускПовторный запуск является новой проверкой и использует текущую настройку. Результат прежнего запуска не меняется.
BR-008Уникальность документа внутри комплектаВ одном комплекте не допускаются две или более строки с одинаковыми значениями полей "Вид документа" и "Подвид документа". Одинаковая пара значений в разных комплектах допускается.
BR-009Максимальное количество комплектовДля одного онлайн-продукта может быть настроено не более пяти комплектов.

Функциональные требования

Настройка справочника

КодТребованиеОписание
FR-GEDK-001Отображать комплектыНа вкладке "Комплекты документов" ГЭДК должен отображать документы выбранного продукта с группировкой по комплектам.
FR-GEDK-002Создавать комплектПо действию "Добавить комплект" ГЭДК должен создать новый комплект после всех существующих комплектов продукта.
FR-GEDK-003Присваивать номерГЭДК должен автоматически присвоить новому комплекту следующий номер без участия пользователя.
FR-GEDK-004Отображать наименование комплектаГЭДК должен отображать наименование каждой группы документов в формате "Комплект N", где N - автоматически присвоенный номер комплекта.
FR-GEDK-005Добавлять документПользователь должен иметь возможность добавить строку документа внутрь выбранного комплекта с заполнением существующих полей комплекта.
FR-GEDK-006Изменять документПользователь должен иметь возможность изменить существующую строку документа внутри комплекта.
FR-GEDK-007Удалять документПользователь должен иметь возможность удалить строку документа из комплекта.
FR-GEDK-008Удалять комплектПользователь должен иметь возможность удалить выбранный комплект, если после удаления у продукта остается не менее одного комплекта.
FR-GEDK-009Перенумеровывать комплектыПосле удаления комплекта ГЭДК должен перенумеровать оставшиеся комплекты от 1 без пропусков, сохранив их взаимный порядок.
FR-GEDK-010Требовать документ в комплектеГЭДК не должен сохранять настройку продукта, если хотя бы один комплект не содержит ни одной строки документа.
FR-GEDK-011Показывать операторыГЭДК должен отображать "И" между документами одного комплекта и "ИЛИ" между комплектами как неизменяемые элементы интерфейса.
FR-GEDK-012Сохранять действующие поляДля строки документа должны сохраняться существующие поля: вид досье, вид документа, подвид документа и применимые атрибуты связки.
FR-GEDK-013Применять действующие праваПросмотр и изменение комплектов должны использовать действующие права на просмотр и изменение справочника "Онлайн-продукты". Новая роль данным ТЗ не вводится.
FR-GEDK-014Проверять строку документаГЭДК не должен сохранять настройку продукта, если обязательное существующее поле хотя бы одной строки документа не заполнено.
FR-GEDK-015Не отображать статусы комплектовГЭДК не должен отображать для комплектов пометки "Основной", "Альтернативный" или иные признаки категории комплекта.
FR-GEDK-016Проверять уникальность документовПри сохранении настройки ГЭДК должен проверить каждый комплект на наличие строк с одинаковыми значениями полей "Вид документа" и "Подвид документа". При обнаружении хотя бы одной одинаковой пары ГЭДК не должен сохранять настройку продукта.
FR-GEDK-017Показывать дублирующие строкиЕсли в одном комплекте обнаружены строки с одинаковыми значениями полей "Вид документа" и "Подвид документа", ГЭДК должен выделить эти строки и показать сообщение о повторении документа внутри комплекта.
FR-GEDK-018Ограничивать количество комплектовЕсли для онлайн-продукта уже настроено пять комплектов, ГЭДК не должен создавать шестой комплект и должен показать сообщение о достижении максимального количества комплектов.

Онлайн-верификация

КодТребованиеОписание
FR-VER-001Использовать текущую настройкуДля нового или повторного запуска ГЭДК должен использовать настройку справочника, действующую на момент начала этого запуска.
FR-VER-002Проверять комплекты по порядкуГЭДК должен проверять комплекты по возрастанию автоматически присвоенного номера.
FR-VER-003Определять полный комплект документовГЭДК должен признать комплект полным только после успешной проверки каждого входящего в него документа.
FR-VER-004Применять условие "ИЛИ"ГЭДК должен считать продукт успешно проверенным после определения полного комплекта документов для любого одного настроенного комплекта.
FR-VER-005Выбирать первый полный комплект документовЕсли полными признаны несколько комплектов, ГЭДК должен использовать первый из них по порядку настройки.
FR-VER-006Останавливать проверкуПосле определения первого полного комплекта документов ГЭДК не должен проверять последующие комплекты.
FR-VER-007Не формировать лишние расхожденияПри успешном результате ГЭДК не должен формировать отсутствующие документы или иные расхождения по остальным комплектам.
FR-VER-008Применять проверку ind_doc_51 к комплектуЕсли проверяемый комплект содержит ind_doc_51, ГЭДК должен проверить документы этого вида в досье БПК и связанном досье счета с применением действующих правил поиска документов и определения связи между досье.
FR-VER-009Не запускать проверку ind_doc_51 для последующего комплектаЕсли до комплекта с ind_doc_51 определен полный комплект документов без ind_doc_51, ГЭДК не должен выполнять поиск связанного досье счета для последующего комплекта.
FR-VER-010Формировать неуспешный результатЕсли по результатам проверки полный комплект документов не определен, ГЭДК должен сформировать расхождения только по документам Комплекта 1, наличие которых в требуемом месте не подтверждено.
FR-VER-011Исключать последующие комплекты из неуспешного результатаЕсли по результатам проверки полный комплект документов не определен, ГЭДК не должен включать в результат документы комплектов с номером 2 и далее.
FR-VER-012Ограничивать тип расхожденияЕсли по результатам проверки полный комплект документов не определен, ГЭДК должен выводить только отсутствие документов Комплекта 1 и не должен выводить ошибки размещения, отсутствия связи, неоднозначной связи или недоступности связанного досье.
FR-VER-013Не пересчитывать историюПосле изменения справочника ГЭДК не должен автоматически пересчитывать результаты завершенных запусков.
FR-VER-014Не хранить версии настройкиГЭДК не должен создавать пользовательскую историю версий комплектов для выбора при онлайн-верификации.

FR-DATA-002Обеспечить полную заменуПосле перехода в действующей конфигурации не должны одновременно использоваться старые строки комплекта и новые комплекты.
FR-DATA-003Удалить старые настройкиПосле подтверждения загрузки новых данных старые настройки должны быть удалены из действующей конфигурации.
FR-DATA-004Выбрать технический способ переходаФормат файла, порядок загрузки, технический способ удаления и процедура переключения определяются вендором и не задаются настоящим ТЗ.
FR-DATA-005Проверять уникальность импортируемых документовДо загрузки новых настроек вендор должен проверить каждый импортируемый комплект на наличие строк с одинаковыми значениями полей "Вид документа" и "Подвид документа". При обнаружении одинаковой пары загрузка новых настроек не должна начинаться до устранения дубликата.
FR-DATA-006Проверять количество импортируемых комплектовДо загрузки новых настроек вендор должен проверить количество комплектов каждого онлайн-продукта. Если для продукта подготовлено более пяти комплектов, загрузка новых настроек не должна начинаться до сокращения их количества.

  • Не признавать текущий комплект полным.
  • Если полный комплект документов не определен, включить в результат требуемые документы Комплекта 1, наличие которых не подтверждено.

  • Не учитывать документ при определении полного комплекта документов.
  • Если полный комплект документов не определен, вывести отсутствие этого документа в составе Комплекта 1.
  • Не выводить отдельную ошибку размещения.
Проверка продолжается. Если полный комплект документов не найден, формируется результат только с отсутствующими документами Комплекта 1.
EXC-KIT-006Дублирование документа внутри комплектаВ одном комплекте существуют две или более строки с одинаковыми значениями полей "Вид документа" и "Подвид документа".
  • Не сохранять настройку продукта.
  • Выделить все дублирующие строки.
  • Показать сообщение о повторении документа внутри комплекта.
Прежняя настройка продукта остается действующей.
EXC-KIT-007Превышение количества комплектовДля онлайн-продукта уже настроено пять комплектов, и пользователь пытается добавить еще один комплект.
  • Не создавать новый комплект.
  • Показать сообщение о достижении максимального количества комплектов.
Для продукта сохраняются пять ранее настроенных комплектов.
