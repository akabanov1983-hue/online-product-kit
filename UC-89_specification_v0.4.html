Назначение документа

Настроить полные комплекты для разных способов оформления онлайн-продукта. Проверка документов и ее результаты описаны в UC-68.

Термины

ТерминОпределение
ГЭДКПрограммный комплекс "Гибридное электронное досье клиента".
Комплект документовПеречень видов и подвидов документов для одного способа оформления продукта. В интерфейсе называется "Комплект N". Сохраненный комплект содержит хотя бы одну заполненную строку.
Комплект 1Первый из оставшихся комплектов по текущему номеру. После удаления комплекта номера присваиваются заново без пропусков.
Уполномоченный пользователь ГЭДКПользователь с правом просмотра справочника. Изменение доступно только при наличии права изменения справочника.
Пара вида и подвидаСочетание значений "Вид документа" и "Подвид документа". Совпадение только одного значения не означает повторения пары.

Границы и ответственность

ОбластьПравило
Входит в объем
  • Модель и интерфейс настройки комплектов.
  • Проверки при добавлении, изменении и сохранении.
  • Импорт и экспорт конфигурации между средами.
  • Подтверждение замены настроек продуктов из файла.
Вне объема
  • Алгоритм верификации, сохранение ее результатов и отчеты - UC-68.
  • Изменение контракта POST /file/product/async.
  • Пользовательская история версий настроек.
  • Пересчет старых результатов после изменения настроек.
ПользовательПросматривает, редактирует, импортирует и экспортирует настройки в пределах действующих прав.
ГЭДКХранит состав и порядок комплектов, проверяет настройку, выполняет импорт и экспорт.
ВендорОпределяет формат файла и сопоставление справочников между средами. Подтверждает поведение при техническом сбое импорта.
Создание и очистка справочникаСоздание продукта проверяется вместе с настройкой комплектов. При переходе старые пустые настройки удаляются.

Бизнес-правила

КодПравилоОписание
BR-001Полнота комплектаКаждый комплект содержит все документы, необходимые для одного способа оформления продукта.
BR-002Автоматические операторы
  • Документы одного комплекта объединяются условием "И".
  • Комплекты объединяются условием "ИЛИ".
  • Пользователь не изменяет операторы.
BR-003ПорядокКомплекты расположены по взаимному порядку создания. После удаления оставшиеся комплекты сохраняют взаимный порядок и получают номера от 1 без пропусков.
BR-008Уникальность вида и подвидаПара "Вид документа + Подвид документа" может быть указана только один раз в настройке онлайн-продукта. В другом онлайн-продукте эту пару использовать можно.
BR-009Количество комплектовВ настройке онлайн-продукта должно быть от 1 до 10 комплектов. В каждом комплекте должна быть хотя бы одна полностью заполненная строка документа.
BR-010Один комплект при оформленииПри одном оформлении онлайн-продукта используется только один комплект. Все документы этого оформления, указанные в настройке продукта, должны относиться к нему.
BR-011Определение комплекта

ГЭДК определяет комплект по виду и подвиду найденного документа. Учитываются только документы конкретного оформления и пары из настройки этого продукта. Действующие условия поиска документов сохраняются.

Почему это важно. Это правило позволяет однозначно определить комплект по найденному документу. Без уникальности пар и использования одного комплекта документы могут указывать на разные комплекты. Тогда потребуется отдельный алгоритм выбора. Поиск и проверка документов станут сложнее.

Функциональные требования

КодТребованиеОписаниеКритерий приемки
FR-GEDK-001Отображать комплектыГЭДК должен показывать документы выбранного продукта по комплектам. При создании продукта можно показать пустую рабочую настройку. Сохранить ее нельзя.После добавления первого документа на экране есть Комплект 1. Пустая рабочая настройка не сохраняется.
FR-GEDK-002Создавать комплектПо действию "Добавить комплект" ГЭДК должен добавить рабочую группу после существующих комплектов. Группа сохраняется только после добавления заполненного документа.При существующих Комплектах 1 и 2 новый комплект появляется после Комплекта 2.
FR-GEDK-003Присваивать номерГЭДК должен автоматически присвоить новому комплекту следующий номер без участия пользователя.Созданный после Комплекта 2 комплект получает номер 3 без ручного ввода.
FR-GEDK-004Отображать наименование комплектаГЭДК должен отображать наименование каждой группы документов в формате "Комплект N", где N - автоматически присвоенный номер комплекта.Заголовок группы с номером 3 имеет текст "Комплект 3".
FR-GEDK-005Добавлять документГЭДК должен добавлять строку документа в комплект, указанный пользователем.Добавленная строка отображается в выбранном комплекте и отсутствует в остальных.
FR-GEDK-006Изменять документГЭДК должен предоставлять пользователю с правом изменения справочника редактирование существующей строки документа.Изменение строки доступно с правом изменения и сохраняет выбранные новые значения.
FR-GEDK-007Удалять документПосле подтверждения ГЭДК должен удалить строку из рабочего состава комплекта. Сохранение допускается только при соблюдении правил заполнения комплектов.Последний документ удален из рабочего состава. До сохранения пользователь добавляет документ или удаляет этот комплект, если есть другие заполненные комплекты.
FR-GEDK-008Удалять комплектГЭДК должен удалять выбранный комплект после подтверждения. Сохранить изменение можно, только если остается хотя бы один заполненный комплект.Удаление одного из двух комплектов сохраняется. Удаление единственного комплекта без замены не сохраняется.
FR-GEDK-009Перенумеровывать комплектыПосле удаления ГЭДК должен перенумеровать оставшиеся комплекты от 1 без пропусков. Порядок оставшихся комплектов сохраняется.Удалить Комплект 2 из трех: прежний Комплект 3 становится Комплектом 2.
FR-GEDK-010Требовать документ в комплектеГЭДК не должен сохранять комплект без полностью заполненной строки документа.
  • Продукт с пустым комплектом не сохраняется.
  • Продукт с одним заполненным комплектом сохраняется.
FR-GEDK-011Показывать логические операторыГЭДК должен отображать "И" между документами одного комплекта и "ИЛИ" между комплектами как неизменяемые элементы интерфейса.На экране между документами виден "И", между комплектами - "ИЛИ"; изменение операторов недоступно.
FR-GEDK-012Сохранять действующие поляДля строки документа должны сохраняться существующие поля: вид досье, вид документа, подвид документа и применимые атрибуты связки.После сохранения прочитать настройку: вид досье и применимые атрибуты связи сохранены. Место их редактирования уточняется у вендора.
FR-GEDK-013Применять действующие праваПросмотр и изменение комплектов должны использовать действующие права на просмотр и изменение справочника "Онлайн-продукты". Новая роль не вводится.Пользователь с правом просмотра видит настройки, но не может изменять их.
FR-GEDK-014Проверять строку документаГЭДК не должен сохранять настройку, если в строке документа не заполнено обязательное поле.При незаполненном обязательном поле сохранение отклоняется. Прежняя настройка остается действующей.
FR-GEDK-015Проверять уникальностьПри сохранении ГЭДК должен отклонять настройку продукта, содержащую повторяющуюся пару вида и подвида документа в любых его комплектах.Повтор пары из Комплекта 1 в Комплекте 2 блокирует сохранение. Та же пара в другом продукте не блокируется.
FR-GEDK-016Сообщать о повторенииПри повторении пары ГЭДК должен сообщать пользователю, какая пара уже настроена и в каком комплекте она находится.Сообщение содержит повторяющиеся значения и комплект с уже настроенной парой.
FR-GEDK-017Ограничивать количествоЕсли у продукта существует 10 комплектов, ГЭДК не должен создавать одиннадцатый комплект.Создание десятого комплекта разрешено; попытка создания одиннадцатого не меняет состав.
FR-GEDK-018Сообщать о лимитеПри попытке создания одиннадцатого комплекта ГЭДК должен показывать сообщение о достижении максимального количества комплектов.При 10 комплектах видна причина отказа в создании.
FR-GEDK-019Не хранить пользовательские версииГЭДК не должен создавать пользовательскую историю версий настройки комплектов. Это ограничение не относится к хранению результатов верификации и истории расхождений.После изменения настройки нет пользовательского списка ее версий; сохраненный результат проверки доступен в UC-68.
FR-GEDK-020Проверять добавляемую паруГЭДК должен отклонять добавление строки, если такая пара вида и подвида уже существует в любом комплекте этого продукта.При попытке добавить пару из другого комплекта новая строка не появляется.
FR-GEDK-021Проверять изменяемую паруГЭДК должен отклонять изменение строки, если новая пара вида и подвида совпадает с парой любой другой строки этого продукта.Изменение пары на уже существующую отклоняется; сохранение строки без изменения ее пары допускается.
FR-GEDK-022Создавать первый комплект с документомГЭДК должен создать Комплект 1 после успешного добавления первого документа. Продукт и заполненный комплект сохраняются вместе.Создание продукта с первым заполненным комплектом завершается успешно. Отдельное сохранение продукта без комплекта отклоняется.
FR-GEDK-023Не создавать пустой комплект при отменеПри отмене или ошибке добавления первого документа ГЭДК не должен сохранять новый продукт и Комплект 1.Пользователь отменил первое добавление. Новый продукт без документов не появился в справочнике.
FR-GEDK-024Проверять создание продуктаГЭДК должен проверять настройку при создании карточки онлайн-продукта.Карточка сохраняется только с 1-10 заполненными комплектами.
FR-GEDK-025Проверять все способы сохраненияГЭДК должен применять одинаковые ограничения при создании, изменении и импорте настройки.Пустую настройку нельзя сохранить через интерфейс или другой способ записи.
FR-GEDK-026Требовать комплект у продуктаГЭДК не должен сохранять продукт без комплектов документов.Сохранение продукта с нулем комплектов отклоняется.

Импорт и экспорт конфигурации

КодТребованиеОписаниеКритерий приемки
FR-DATA-001Экспортировать конфигурациюГЭДК должен выгружать конфигурацию справочника "Онлайн-продукты" в файл для переноса между средами.Экспортированный файл доступен пользователю и пригоден для импорта в целевой среде.
FR-DATA-002Импортировать конфигурациюГЭДК должен загружать настройки из экспортированного файла без ручного ввода строк.Импорт экспортированного файла переносит настройки существующих продуктов.
FR-DATA-003Сохранять состав при переносеПосле импорта состав и порядок комплектов, виды досье, виды и подвиды документов и применимые атрибуты связи должны соответствовать экспортированной конфигурации.Сравнить настройки в исходной и целевой средах: состав, порядок и все поля, используемые при проверке документов, совпадают.
FR-DATA-004Отклонять продукты без комплектовГЭДК должен отклонять импорт продукта без комплектов документов.Файл содержит продукт без комплектов. Импорт отклоняется до изменения действующей настройки.
FR-DATA-005Проверять файл до измененияДо изменения настройки ГЭДК должен проверить файл. Проверяются заполнение, количество комплектов и наличие используемых справочников в целевой среде.Файл с неизвестным видом документа отклонен до изменения настроек.
FR-DATA-006Проверять количествоГЭДК должен отклонять импорт, если у продукта меньше одного или больше 10 комплектов.Файл с 0 или 11 комплектами отклоняется. Действующая настройка не меняется.
FR-DATA-007Подтверждать заменуГЭДК должен запрашивать подтверждение замены настроек продуктов из файла после успешной проверки файла.До подтверждения замены сохраненная конфигурация не меняется.
FR-DATA-008Проверять пары при импортеГЭДК должен отклонять импорт файла с повторением пары вида и подвида в любых комплектах одного продукта.Повтор пары между Комплектами 1 и 2 блокирует импорт всего проверяемого файла.
FR-DATA-009Отклонять пустые созданные комплектыГЭДК должен отклонять импорт, если любой комплект не содержит заполненного документа.Файл с пустым комплектом отклоняется. Файл с нулем комплектов также отклоняется.
FR-DATA-010Сохранять настройку при отказеПри ошибке проверки файла или отмене подтверждения ГЭДК не должен изменять действующую конфигурацию.Сравнение до и после ошибки проверки или отмены подтверждает отсутствие изменений.
FR-DATA-011Ограничивать экспорт правамиГЭДК должен предоставлять экспорт пользователю с правом просмотра справочника.Экспорт доступен с правом просмотра.
FR-DATA-012Ограничивать импорт правамиГЭДК должен предоставлять импорт пользователю с правом изменения справочника.С одним правом просмотра импорт недоступен.
FR-DATA-013Удалить старые пустые комплектыПри переходе ГЭДК должен удалить пустые комплекты из существующих настроек.У продукта есть пустой и заполненный комплекты. Пустой комплект удален, заполненный сохранен.
FR-DATA-014Удалить продукты без комплектовПри переходе ГЭДК должен удалить из справочника продукты без заполненных комплектов документов.Продукт не имеет комплектов или содержит только пустые комплекты. После очистки он отсутствует в справочнике.
FR-DATA-015Сохранить документы и результатыУдаление пустых настроек не должно удалять документы клиентов и сохраненные результаты проверки.После очистки ранее сохраненные документы и результаты проверки доступны.

Состав вкладки и формы добавления

IDЭлементТипСодержаниеДоступность
UI-KIT-E01Вкладка "Комплекты документов"ВкладкаОтображает настройку комплектов документов выбранного онлайн-продукта.Доступна в карточке онлайн-продукта пользователю с правом просмотра справочника.
UI-KIT-E02"Обновить"КнопкаПовторно загружает сохраненную настройку комплектов выбранного продукта.Отображается постоянно на вкладке.
UI-KIT-E03"Добавить документ"КнопкаОткрывает форму добавления документа в комплект.Кнопка "Добавить документ" доступна уполномоченному пользователю независимо от наличия комплектов. При отсутствии комплектов ГЭДК открывает форму добавления документа с выбранным значением "Комплект 1".
UI-KIT-E04"Добавить комплект"КнопкаСоздает новый комплект после существующих.Доступна с правом изменения. При 10 комплектах одиннадцатый не создается.
UI-KIT-E05"Удалить"КнопкаУдаляет выбранную строку документа после подтверждения.Доступна после выбора строки документа пользователем с правом изменения справочника.
UI-KIT-E06Пояснение операторовТекст
  • "И" - документы входят в один комплект.
  • "ИЛИ" - комплекты являются альтернативными.
Отображается постоянно. Недоступно для изменения.
UI-KIT-E07Заголовок комплектаГруппа строкНаименование в формате "Комплект N", где N - автоматически присвоенный номер.Отображается перед строками документов каждого комплекта.
UI-KIT-E08Состав комплектаТаблица
  • Выбор строки.
  • Комплект.
  • Номер.
  • Вид документа.
  • Подвид документа.
Строки сгруппированы по комплектам и отображаются по возрастанию номера комплекта.

Вопросы на уточнение

КодКомуВопросПримеры или варианты
B-01БизнесСогласовать использование одного комплекта при оформлении продукта. Комплект определяется по виду и подвиду документа.
  • При одном оформлении продукта используется один комплект. Все настроенные документы этого оформления относятся к нему.
  • ГЭДК определяет комплект по виду и подвиду найденного документа. Документы других оформлений не учитываются.
  • Если найдены документы разных комплектов, ГЭДК фиксирует нарушение. Выбор по номеру или количеству найденных документов не выполняется.
  • Просим подтвердить правило. Также нужно согласовать сообщение об ошибке, строки отчета, уведомление и порядок исправления.
  • Без этого правила потребуется отдельный алгоритм выбора комплекта. Поиск и проверка документов станут сложнее.
V-02ВендорУточнить перенос конфигурации и поведение при сбое после начала замены.
  • Полный состав переносимых полей продукта и настройки.
  • Сопоставление продуктов, видов досье, видов и подвидов документов между средами.
  • Сохраняются ли старые настройки всех продуктов файла при техническом сбое в ходе импорта.
  • Обработка повторного импорта и восстановление после частичной загрузки.
V-05ВендорКак обрабатывать старую настройку с пересечением пар между разными неполностью одинаковыми комплектами?
  • Новый ввод и импорт должны отклонять повтор пары в одном продукте.
  • При верификации полностью одинаковые старые комплекты пропускаются после первого.
  • Поведение для частично пересекающихся старых комплектов отдельно не определено.
