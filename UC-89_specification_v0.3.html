Назначение документа

Настроить для одного онлайн-продукта альтернативные самодостаточные комплекты. Проверка документов и отражение ее результатов описаны в UC-68.

Изменения этой версии сравниваются с непосредственно предыдущим проектом UC-89_specification_v0.2.html. Основание новой редакции - явное бизнес-решение пользователя от 01.10.2026. Подтверждение заказчиком остается отдельным этапом согласования.

Бизнес-правила

КодПравилоОписаниеИсточник
BR-001СамодостаточностьКаждый комплект содержит все документы, необходимые для одного способа оформления продукта. Положение о включении одного общего документа в каждый комплект удалено, поскольку повтор пары в настройке продукта запрещен.S1: BR-001; S4: строки 229-244
BR-002Автоматические операторы
  • Документы одного комплекта объединяются условием "И".
  • Комплекты объединяются условием "ИЛИ".
  • Пользователь не изменяет операторы.
S1: BR-002
BR-003ПорядокКомплекты расположены по взаимному порядку создания. После удаления оставшиеся комплекты сохраняют взаимный порядок и получают номера от 1 без пропусков.S1: BR-003, FR-GEDK-009
BR-008Уникальность в онлайн-продуктеКаждая пара "Вид документа + Подвид документа" должна входить только в одну строку одного комплекта данного онлайн-продукта. Одинаковая пара в разных онлайн-продуктах допускается.S4: строки 203-246; S6
BR-009КоличествоДля одного онлайн-продукта допускается от нуля до 10 комплектов. Каждый сохраненный комплект содержит хотя бы одну полностью заполненную строку.S3: BR-009; S1: FR-GEDK-010
BR-010Один комплект при оформленииПри оформлении конкретного экземпляра онлайн-продукта должен использоваться только один из настроенных комплектов документов. Документы, относящиеся к этому оформлению и предусмотренные настройкой онлайн-продукта, должны принадлежать одному комплекту.S6: решение пользователя от 01.10.2026
BR-011Идентификация по виду и подвидуПри непересекающейся настройке принадлежность найденного документа к комплекту определяется по паре "Вид документа + Подвид документа" в пределах одного онлайн-продукта. Для определения итогового комплекта учитываются только документы, отобранные действующими правилами поиска для проверяемого экземпляра продукта.S6: решение пользователя от 01.10.2026

Обоснование бизнес-правила

Уникальность пар в настройке и использование одного комплекта при оформлении позволяют однозначно определить итоговый комплект по найденному документу. Без этих условий документы могут указывать на несколько комплектов: потребуется отдельный алгоритм выбора, что существенно усложнит поиск и проверку документов при верификации и определение комплекта в целом.

Статус решения: включено в проект ТЗ по указанию пользователя. Подтверждение заказчиком запрашивается в письме. Уникальность пары в настройке не обеспечивает соблюдение правила одного комплекта при фактическом оформлении продукта.

Пользователь указал: при выдаче конкретного экземпляра онлайн-продукта используется только один комплект, содержащий уникальный перечень пар вида и подвида документа. Зафиксированные уточнения от 01.10.2026

Уточнения пользователя к опубликованному письму являются основанием текущей редакции требований.

  • У каждого пользователя уникальный адрес электронной почты. Один адрес не может принадлежать нескольким пользователям.
  • Проверка документов запускается только при поступлении запроса из УОС и выполняется автоматически.
  • Формирование отчета не запускает проверку документов и использует сохраненные результаты.

Вопрос V-03 о составе экранов настройки строки документа исключен из текущего согласования по указанию пользователя как не относящийся к данному ТЗ. Правила использования одного комплекта и остальные открытые вопросы сохраняют прежний статус.

Фиксация устранения расхождения по событию документа или связи не является запуском процесса верификации. Формирование отчета читает состояние сохраненных результатов.

Редакция от 01.10.2026 учитывает комментарии 1-3 к опубликованному письму. Измененные правила, требования, сценарии, критерии приемки, вопросы и риски проверены на согласованность между UC-89, UC-68 и письмом. Бизнес-правило одного комплекта остается решением для согласования заказчиком.
